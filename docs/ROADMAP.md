# Milestones — proposed (not yet scheduled)

## Gate 0 — engine viability

Run ENGINE_SPIKES.md 0–3. **Do not build broad gameplay yet.** Decide if portable Papyrus+CK approach can meet the needs. Output: versioned technical report with replicable demonstrations.

## v0.1 — colony registry + recruitment

Single outpost; beacon, persistent residents, stats-based recruit quality, cap and settings. Preserve Bard's precedent, but implement our own system; do not clone proprietary mod files.

## v0.2 — housing + work

Household assignment, player home, beds, job stations, basic skill effects, deterministic production.

## v0.3 — food + needs + logistics

Stockpile, nutrition, needs, economy, transport; support unloaded outposts with validated batch simulation.

## v0.4 — security

Guard shifts, posts, patrols, raids, equipment swap + restoration, consequences for poor security.

## v0.5 — plots and levels

Three-level fixed-footprint housing/work plots with upgrade prerequisites from needs, services, skills, population, and infrastructure.

## v0.6 — story and family

Relationships/households, optional child and elder archetypes, unique NPCs, questlines. Respect authoring/animation constraints.

## v1.0 candidate — sustainable colony gameplay

Measured performance and save stability across multiple outposts; documentation, installer, compatibility patches, localization and balance.

## Long term

Regional inter-outpost commerce, higher-capacity cities, more authored models, sophisticated city plans, native optional enhancements if validated.
